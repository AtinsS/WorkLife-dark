# WorkLife Dark

A dark companion theme for WorkLife Calendar. It carries the same character: night sky, indigo-violet accent, quiet surfaces — so the calendar, tasks, timer, habits, and finances feel like **one system**, not a plugin on top of someone else's theme.

> **v1.0.0** · Obsidian 1.4.0+ · [AtinsS](https://github.com/AtinsS)

---

## Why

WorkLife Calendar brings planning, execution, and analysis into a single window. The theme picks up that idea: **quiet background — bright data**. The backdrop breathes and lives, but never argues with numbers, timers, or charts.

- **Night sky instead of a flat background.** Layered gradient, star dust, glow around the edges.
- **Falling stars.** Four animations with different periods — noticeable, never intrusive.
- **Twinkle.** Stars "breathe" in four layers, phases out of sync — the scene never freezes.
- **Surfaces under content.** Menus, modals, sidebars — opaque. The sky never bleeds through expense tables or the calendar grid.
- **One accent for everything.** Indigo-violet `#8b6cff` — in tabs, checkboxes, tags, callouts, charts.
- **Readability.** `Inter` + `JetBrains Mono`, line-height 1.75 — for long notes and reports.

Visually matches the plugin's interface: same palette, same radii, same shadows.

---

## Installation

1. Drop the folder into `<Vault>/.obsidian/themes/WorkLife Dark/` — it should contain `manifest.json` and `theme.css`.
2. **Settings → Appearance → Theme → WorkLife Dark.**
3. Install [WorkLife Calendar](https://github.com/AtinsS/WorkLife-Calendar-for-Obsidian) — the theme is built around its widgets.
